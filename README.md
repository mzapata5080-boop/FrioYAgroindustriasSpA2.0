# Frío y Agroindustrias SpA

Frontend independiente: `frontend/` (HTML, Bootstrap, JavaScript). Para que
la ruta relativa del logo resuelva, sirva el repositorio desde su raíz y abra
`/frontend/`.
Backend: Django con JSON, sesión, CSRF y PostgreSQL/Supabase o SQLite local.

Consulta **LEEME_PRIMERO.md** para ejecutar, probar y revisar los cambios y el estado de las migraciones.

Para descuentos, precios, ejemplos de cálculo y la migración comercial pendiente, consulta `docs/DESCUENTOS_PRECIOS.txt`.
